# VIDAA Video Test

Static HTML5 page that checks what a TV browser (built for Hisense VIDAA, works anywhere) can decode:
MSE, H.264, VP9, AV1, AAC, Opus, 1080p / 1080p60 / 4K, full screen, frame drops, sound.
Controls: arrows, OK, Back. The result is printed on screen ("Итог" button) so it can be photographed.

- No server, no cookies, no network calls except loading its own files from `media/`.
- Test clips are synthetic (ffmpeg `testsrc2` + noise + beeps), 6 s each, generated by `media/gen.sh`
  and released under CC0. The `v_*` / `a_*` files are the same streams split into separate
  video/audio tracks (as a DASH player uses them) and remuxed without re-encoding.
- Passing these tests does not prove that any third-party site (e.g. an Invidious instance) can play YouTube videos.
